# FusionCart

## Descriere

FusionCart este o aplicație full-stack pentru comenzi.

- **Frontend** dezvoltat cu Next.js, React și TypeScript
- **Backend** dezvoltat cu NestJS și TypeScript

---

# Frontend

## Repository

GitHub: https://github.com/avramcr/FrontendRinf

## Instalare

```bash
git clone https://github.com/avramcr/FrontendRinf
cd FrontendRinf
npm install
```

## Rulare aplicație

```bash
npm run dev
```

## Tehnologii utilizate

- Next.js
- React
- TypeScript
- PostgreSQL

---

# Backend

## Repository

GitHub: https://github.com/avramcr/BackendRinf

## Instalare

```bash
git clone https://github.com/avramcr/BackendRinf.git
cd BackendRinf
npm install
```

## Rulare aplicație

```bash
npm run start:dev
```

## Tehnologii utilizate

- NestJS
- TypeScript

---

# Pornire proiect complet

1. Pornește backend-ul:

```bash
cd BackendRinf
npm install
npm run start:dev
```

2. Într-un terminal separat, pornește frontend-ul:

```bash
cd FrontendRinf
npm install
npm run dev
```
