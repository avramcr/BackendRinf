# FusionCart Backend
## Repository

GitHub: [FusionCart Backend Repository](https://github.com/avramcr/BackendRinf)

## Instalare

```bash
git clone https://github.com/avramcr/BackendRinf.git
cd BackendRinf
npm install
```

## Rulare aplicație

```bash
npm run start:dev
```

## Tehnologii utilizate

* NestJS
* TypeScript
